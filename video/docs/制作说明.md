# 映销 · 复赛宣传片制作基准

模式：自主自由创作；用户已明确授权直接制作。规格：90 秒、1920×1080、30fps、中文旁白与烧录字幕。交付带配乐/无配乐两版、SRT、可编辑 Remotion 工程与本地工作台。

## 产品简报与执行决策

面向复赛评委与门店营销人员，解释「一条营销需求如何成为有证据、可修改、可导出的图文」。以实际工作流和可辨识页面为核心，不做纯概念短片。

| 用户要求/产品依据 | 制作决策 |
|---|---|
| 90 秒横屏、中文旁白字幕 | 2700 帧；旁白逐镜合成，字幕按语义短句分段，字号 64px |
| 暖白、朱红、圆角的真实工作台 | 复用 #bd302e / #252931 / #f6f5f4；Microsoft YaHei；圆角 13–26px |
| 多阶段 Agent、独立审核、局部改稿 | 分开给出策略、取证、生成、审核、修改、导出镜头，每镜一个重点 |
| 现有真实回归与页面 | 从原生 web 页面载入 2026-10-18 已保存的真实模型结果，冻结页面状态采集；不用新模型响应替代历史证据 |
| 本地资料，非实时 ima | 镜头注记「本地资料 · 历史实测画面」；不宣称实时联网、官方背书或云端上线 |
| 存在本机路径、会话 ID 等 | 采集前移除会话 ID、内部绝对路径、账单用量；外观产品图仅从已有导出加载 |
| 清晰的产品解说 | 女声中文神经合成旁白；低音量节奏底与少量电影系 SFX，旁白优先 |

## 视觉方向

考虑「红白编辑排版」「暗色科技空间」「纸墨印刷」。选红白编辑排版：最接近真实界面，能承载证据、段落和来源，且电脑产品图片在暖白底清晰。放弃大面积霓虹；不套用 Ink Press 的字体或配色。

字体：Microsoft YaHei（原站 Windows 字体）；主标题 90–136px / 600–700，功能副句 38–46px，字幕 64px。色板：bg #f6f5f4、surface #fff、ink #252931、muted #777780、accent #bd302e、soft #f1e8e5、success #4a795b。栅格：96px 边距，12 列；圆角 13/24px；边框 #eeedf0。图片与真实 UI 卡片使用柔和接触影，不额外改造产品 UI。

动效性格：清晰、沉稳、有推进感。专业信赖预设；普通入场 21–30f，bezier(0,0,.2,1)，无弹跳；文字 blur-slide 共享三通道进度；结尾沿指定镜头卡用轻过冲。相机稳定，信息密集处正视。品牌落定停留至少 30f；收尾集合完成后至少 45f 呼吸。

## 音频约束与例外

本片为 90 秒有旁白的产品解说，旁白是叙事主轴。保留节奏底而不逐拍震屏；音乐不会覆盖旁白。SFX 使用来源可追溯的 Mixkit 样本，动作与关键峰值用相对镜头帧号集中管理。配乐来源、合成旁白方式和实际音量测量在音频记录中归档。

遵循 promo-energy-arc 的低开、功能交替、峰值收尾。90 秒解说比默认 30–60 秒更长，故功能段增加读图停留。Q11 真实页面小字属于背景纹理，仅叙事重点用特写与大字重述；不要求观众逐字阅读完整知识库。Q7 不适用：本片无独立实体资产堆叠特写。C3 画外字幕为解说层，不作 3D 页内注记。

## 数据安全与真实性

只在本地渲染。用于配音服务的文本仅为本片公开宣传文案，不含产品知识库原文、客户、密钥或路径。页面由真实 web 源码渲染真实历史结果，采集脚本不修改业务源码；冻结状态为镜头素材，不冒充新一轮实时生成。完整知识库与原始模型日志不随工程交付。
