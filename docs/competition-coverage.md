# v4 赛题覆盖矩阵

核对依据：本地《华为·产业进阶赛道·赛题手册v4(1).pdf》第 4—5 页。资料源约束按本次用户转述的主办方新通知调整为官网/本地/可选 ima；本文件不冒充已取得公开通知链接。下表“已实现”是代码覆盖，不等同每一项真实模型端到端验收通过。

## 四平台

| 平台 | 已实现结构 | 图片 |
|---|---|---|
| 小红书 | 口语场景、短段、话题；不伪造亲身体验 | 3—6 |
| 公众号 | 标题、导语、分段、行动引导 | 2—4 |
| 门店朋友圈 | 单段短文、一个核心卖点、咨询或到店 | 1—3 |
| 门店海报 | 主副标题、最多三个短卖点、CTA、HTML 预览 | 1 |

历史 acceptance 报告记录前三平台和跨型号真实浏览器/API 成功；这是旧链路证据，不能代替当前变更的完整回归。round2 公众号 blocked 证明系统会阻止交付，不能记为通过。

## 八项最低功能

| 最低功能 | 实现与限制 |
|---|---|
| 账号与知识库/数据源 | 凭证留后端，来源和连接状态可查；未实现独立多用户账号登录。ima 按新通知可选，需明确本机运行身份与来源模式 |
| 任务输入 | 产品、人群、场景、平台解析，关键信息不足追问 |
| 知识与图片检索 | 同型号主题检索、策略查询、条件与来源、图片索引；官网新增能力以本轮验收为准 |
| 场景与平台策略 | 独立策略调用、客户洞察、购买阶段、目标与取证计划 |
| 图文软文生成 | 标题、正文、CTA、图片引用和位置，四平台结构约束 |
| 事实核验 | 独立 LLM + 程序检查；不支持/待确认/冲突阻断 |
| 合规检查 | 规则 + 审核，拦截无依据促销、体验、绝对化与比较 |
| 修改与导出 | 当前会话局部段落修改/重规划、复制、Markdown 与 HTML |

八个提示词模块全部实际组装于运行角色；映射见 `prompt-design.md`。

以下为手册内容的准确语义转录，并非另造六个测试任务。

| 手册参考问题 | 当前证据/待测 |
|---|---|
| 为准备开学购机的大学新生生成小红书图文，如何兼顾学习、携带和续航需求？ | 历史学生任务真实成功；续航不能由电池容量推断 |
| 为经常出差的职场用户生成公众号文章，哪些卖点应优先呈现？ | 历史 acceptance 公众号成功；round2 新审核一次阻断，当前需复测 |

## 历史测试证据与复核边界

`output/acceptance/report.md`：真实 DeepSeek 与浏览器验收、21 项当时自动测试，ima 当时受配额阻断。新规则取消 ima 强制后，该阻断不再是赛事必需链路的缺口。

`output/round2/live/`：A-student 与 B-business 各有最终 pass，同时保留先前 blocked/needs_input 记录；C-wechat 为 blocked/pending。`output/round2/conflict-live.json` 为测试注入冲突，不能说原库存在该冲突。`output/round2/unit-round2.txt` 为 12 项规则/模拟测试，不是 12 个真实 API 案例。

原始输出可能包含授权资料和图片链接，默认不公开提交。公开报告只保留必要汇总；本轮新增测试以新生成的验收报告为准，避免把历史成果与新变更混算。
