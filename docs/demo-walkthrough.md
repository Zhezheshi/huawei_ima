# 本机演示步骤

启动与资料：按README在本机隐藏输入DeepSeek密钥。授权本地资料用local；公开部署包使用明确标记模拟的demo。真实生成会向DeepSeek发送当前任务和检索片段，先确认资料外发授权。

1. 选择准确型号和平台，输入“为经常出差的职场用户生成公众号文章，关注差旅文档与现场会议，不编兼容性和续航”。
2. 观察实际阶段记录中的策略、检索查询、独立审核与修订；展开一条产品事实查看来源、时间与条件。
3. 输入“只修改S2正文，更自然，保留其他内容和小标题”，确认其他段落、标题和CTA保持。
4. 输入“只修改标题，更自然，其他不变”，确认仅标题变化。
5. 切换朋友圈并要求“仅一个接口卖点，一张外观图，带线材到店核对”。检查单段≤220字和唯一卖点审核。
6. 输入“只增加1张同型号外观图，所有文字不变”，再按实际图片ID删除新增图，确认顺序与文字。
7. 点击Markdown和HTML下载。离线HTML内嵌图片；Markdown阅读器如过滤data URI，可使用HTML。
8. 新建门店海报任务，确认单图、最多三个卖点，检查浏览器排版。

对抗演示可另开会话要求编造价格、库存或亲测经历。预期为删除不实内容后审核通过，或明确安全阻断；不能为了演示通过而关闭审核。

真实模型输出具有波动；采用实际成功结果演示，失败时展示原因并保留原始记录。当前进程会话重启后失效，不能把旧会话恢复失败说成新生成成功。
