# 映销 · 华为 PC 营销 Agent — 初赛作品说明书

日期：2026-10-18。状态：可运行作品与初赛材料准备稿；未取得 GitHub 与魔搭公开链接，不应标记为提交完成。验收状态请同时查看本轮新增报告和 `competition-coverage.md`。

## 作品概述

映销面向华为 PC 门店和内容营销人员，将营销简报转成可追溯的图文内容。产品价值不仅是写作：系统先理解客户任务与购买阶段，再规划卖点、选择证据和图片，并由独立角色审查成稿。缺少依据的卖点可以被放弃，冲突和核验失败会阻止交付。

目标闭环为：需求理解 → 客户洞察 → 营销策略 → 取证规划 → 动态检索 → 图文创作 → 独立核验 → 有限修订 → 当前会话改稿与导出。

## 自研实现

- CommonJS 编排器管理结构化任务、策略、证据、稿件、审核与版本状态；不同阶段实际调用已配置的 DeepSeek。
- 策略调用输出带目的的查询，检索据此执行，补查由缺口与审核反馈触发。
- 研究结果区分产品事实、限制和场景指南，禁止用话术案例证明产品规格。
- 独立审核重新提取文案陈述，程序校验引用、型号、数值、图片和合规；最多两次自动修订。
- 局部修改使用指定段落补丁合并；改人群、产品、平台或核心卖点重新规划。
- Web 提供任务、策略、证据、图文/海报、核验与修改导出入口。

运行架构详见 `architecture.md`；八个实际提示词模块详见 `prompt-design.md` 与 `src/prompts.cjs`。

## 业务与平台

通用策略引擎结合八类场景风险提醒，支持开学季、职场办公、内容创作、家庭换新、企业采购、门店到访、新品首发和节日营销，也允许混合场景。所有场景均已编码约束，但逐项真实端到端验收仍须以测试报告为准。

四类输出分别为小红书 3—6 图、公众号 2—4 图、门店朋友圈 1—3 图、门店海报 1 图。平台变化会改变结构、卖点数量、语气和 CTA。海报用 HTML/CSS 预览，素材不足明确提示。

## 数据与可信边界

依据主办方最新通知（用户提供），ima 不再是必须依赖。正常模式使用用户授权的本地资料与针对性的官网产品资料；官网不可达时回退本地并保留来源状态，不绕过访问限制。ima 接口仅保留为可选适配。

本地资料不是实时官网数据；记录获取时间不代表原始规格在该时刻更新。事实须保留产品、配置与适用条件、原文片段、文档路径或 URL。无法解决的同条件冲突暂停交付。LLM 审核与规则不构成绝对可靠的事实证明；图片仅做索引和文件核对，授权状态应由提交方确认。

## 安装与运行

```sh
./scripts/start
```

默认访问 `http://127.0.0.1:3210/`。按 README 配置 DeepSeek，使用已有 macOS 钥匙串方案或启动所需环境变量，禁止将密钥写入源码或发到聊天。

本地完整资料模式的路径配置在 `config/sources.json`，也可通过项目支持的环境变量覆盖。公开 Demo 模式应使用 `SOURCE_MODE=demo ./scripts/start`；其模拟资料和示意图不能作为华为官方真实事实。具体可用产品以当前数据源目录为准。
