# 映销 · 华为 PC 营销 Agent 作品说明书

版本：0.4.0（2026-10-23）。源码仓库：https://github.com/Zhezheshi/huawei_ima 。创空间：https://www.modelscope.cn/studios/Zhezheshi/huawei_ima 。本版更新部署鉴权和Demo交互，验收与线上边界见[更新报告](acceptance-2026-10-23.md)；原始真实模型验收仍以10月18日报告为准。

## 目标与实际能力

将营销需求转成有证据、可解释、可修改与可导出的华为PC图文。Agent先解析产品、人群、场景、平台和购买阶段，再规划卖点与查询，检索同型号产品事实、限制、场景指南与图片索引，完成创作、独立审核和有限修订。策略及审核结果实际改变查询、改稿与阻断流程。

支持开学季、职场办公、内容创作、家庭换新、企业采购、门店到访、新品与节日主题及混合场景；四平台为小红书、公众号、门店朋友圈、门店海报。具体通过、失败与未测项以[本轮验收报告](acceptance-2026-10-18.md)和[覆盖矩阵](competition-coverage.md)为准，不能从提示词存在推断为全部稳定通过。

## 架构与实际运行提示词

Node.js 22+、CommonJS，无额外npm依赖；Python 3只用于安全输入密钥。Web入口src/server.cjs；多阶段编排src/orchestrator.cjs；事实和图片src/knowledge.cjs；结构和平台校验src/draft.cjs；展示导出web/content.js。默认本机监听，当前会话在内存中，重启失效。

实际运行的八模块提示词在src/prompts.cjs，每次模型调用均拼接角色任务、场景、平台、知识库、图片、生成、核验和合规规则；各阶段职责不同，使用同一个现有DeepSeek配置，不将文件数量描述成多个独立模型Agent。模型调用次数和API回传Token记录在后端。

## 数据来源与真实性

按用户提供的赛事通知，ima不再强制。本轮真实案例使用已授权的本地华为PC v7资料，关闭官网检索，未将本地数据声称为实时官网或ima。每条证据保留型号、文档、片段、路径/URL、日期和获取时间。关键词检索不是向量检索，未穷尽整库。

部署包只带清晰标记模拟的Demo事实及自绘图，不能作为华为真实产品宣传。正式本地模式需自己取得授权资料；完整库、API密钥、原始输出和未明确许可的图片不进入公开源码或镜像。用户已明确授权本轮检索片段与图片索引文字发送至DeepSeek官方API，未发送整库或图片文件。

## 核验与修订

独立审核从完整可发布文本重新提取事实，不信任作者自列claims；程序检查原始产品事实引用、数值、型号、图片、合规和平台结构。场景标题、核对建议不应被当作参数，但价格、库存、兼容与性能承诺不能通过“非事实”标记豁免。冲突、不支持和待确认未消除时阻止交付。

合法JSON结构错误允许一次修复，之后仍须审核；最多两次针对性审稿修订。朋友圈单段≤220字并审查一个核心卖点；公众号/小红书按项目现有篇幅规则调整；海报单图与最多三个卖点。未满足规则时明确失败，不截断句子、不展示候选稿为成功。

## 交互与导出

支持局部正文修改、只改标题、更换卖点、换平台和图片增删。代码保持未授权范围，失败保留上一通过会话版本。预览、复制正文与导出共享同一内容模块。Markdown和HTML均内嵌图片、附来源与独立核验；部分Markdown阅读器过滤data URI时可使用离线HTML。

## 验证、运行与部署

规则/模拟测试、真实HTTP、真实DeepSeek及浏览器下载分别统计，失败批次保留；详细数量与用量由验收报告记录。运行方法见README，密钥仅通过安全终端临时注入。Windows可用python scripts/with_deepseek.py node src/server.cjs。

Docker部署准备见[部署说明](deployment.md)：Node.js 24、7860端口、模拟资料、精确HTTPS来源和评审口令。已改用页面登录与Cookie会话，提供可选的精确嵌入来源和无密钥健康检查。目标创空间已切换Docker SDK；当前机器无Docker，镜像与线上生成状态以更新报告为准。

## 限制

LLM和规则属于辅助审核，可能漏判或误判；图片只校验索引、型号和文件格式；外观配色描述可引用独立标记的图片索引证据，不能用它证明参数或效果，没有视觉识别或版权审核。未实现独立多用户账号、永久会话、配额计费、自动发布。价格与优惠不作为本版可发布承诺；未知兼容、性能、服务和政策不编造。正式提交前仍需按最新赛题核对格式、素材授权和访问方式。
